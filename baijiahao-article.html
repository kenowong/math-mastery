各位家长朋友好，我是 keno王，一个干了快二十年 IT 的老码农，平时写代码、做产品，也写点技术文章。

今天不聊网络监控，聊一个我自己亲手做的东西——给中小学生用的数学练习工具 math-mastery。这篇文章从头讲起：我为什么做它、怎么做出来的、现在能干啥、你怎么拿到手。想直接拿去用的，拉到文末看获取方式就行。

一、缘起：孩子刷题，刷了个寂寞

我家孩子上初中，数学一直在刷题。但刷着刷着，我发现几个绕不开的痛点：

• 题是做了，但不知道到底哪里不会。错题本记了一堆，下次换个问法又错，到底是哪个知识点没吃透，全凭感觉。
• 市面上的 App 广告多、弹窗多。孩子点进去先来一段 30 秒广告，练两题又弹出"会员才能看解析"，体验很碎。
• 题重复、不讲解。很多题库就是固定那几道，做多了都背下答案了，根本没在思考；做错了也只有个标准答案，没有"为什么这么想"。

作为写代码的人，我第一反应是：与其给孩子换 App，不如自己做一个干净、能讲思路、还能知道孩子哪里弱的工具。于是 math-mastery 就这么开始了。

二、定调：我要的是什么样的工具

动手之前，我先给自己划了四条硬杠，后来也一直没违背：

1. 纯本地、零广告、零联网。不收集孩子任何数据，不弹广告，打开就用。
2. 每个方法有讲解、有例题、最好有图。不能只给题，得告诉孩子"这招怎么用、为什么这么想"。
3. 能出题、且每遍不重样。同一方法，这次练和明天练，题要不一样，避免背答案。
4. 能记录薄弱点，最好能分析。做错的自动记下来，攒多了能告诉我"先攻哪、后攻哪"。

三、技术底座：一个前端网页，没有服务器

我选了最简单的技术路线：纯 HTML + CSS + JavaScript，不接后端、不连数据库。孩子的进度和薄弱点存在浏览器自带的 localStorage 里，关掉网页还在。这样好处很明显：

• 不依赖任何厂商服务，不存在"服务器宕机就用不了"；
• 可以扔到家里 NAS 上，局域网内手机、平板、电脑都能访问；
• 代码完全公开，懂行的家长能自己改、自己部署；
• 最后还能打包成一个单独的 HTML 文件，拷进手机直接打开。

四、第一步：把"方法库"建起来

做数学题，关键是方法，不是题量。所以我按学段把核心解题方法一条条列出来，挨个写讲解、配例题：

• 小学（10 个）：鸡兔同笼、和差倍、植树、盈亏、周期、抽屉原理、容斥、方阵、牛吃草、浓度……覆盖课内常见的"巧算"与"应用题套路"。
• 初中（15 个）：一次函数、二次函数、相似与全等、勾股定理、方程组、分式方程、圆、概率统计、动点问题等。
• 高中（24 个）：数列求和、向量法解立体几何、参数方程求最值、柯西/排序不等式、马尔可夫链、置信区间、假设检验、偏导数、梯度等高阶衔接内容。

后来按家长和孩子反馈，又补了一批拓展技巧，现在一共 127 个技巧。每个方法点开有：文字讲解、"典型例题"（带答案和解析可展开）、以及能动的示意图（比如函数图像怎么画、几何辅助线怎么添）。孩子不是背答案，是看"这一招是怎么想出来的"。

五、第二步：出题引擎——每遍都不重样

光有例题还不够，得能自动出题让孩子练。这里踩过一个大坑：

一开始我做的"再练一组"，其实只是把同一批题打乱顺序，题还是那几道。孩子做两遍就背下来了，等于没练。后来我重做了出题引擎：

• 每个方法用参数化生成：比如"鸡兔同笼"，头数和脚数都是随机算出来的，每道题都不一样；
• 加了跨组去重：连续 10 组练习里，不会重复出现同一道题；
• 题量足够大（每个方法题库扩充到 90 种以上组合），保证反复练也不腻。

这就真正做到了"每天练一组，都是新题"。

六、第三步：学习路径 + 可折叠目录

方法多了，得有条清晰的路径，不然孩子不知道从哪开始。我做了个"学习路径"页：

• 顶部按 学段 → 年级 两级组织（小学一年级到六年级、初中七到九年级、高中十到十二年级）；
• 左侧是可折叠的侧边栏，手机上收成抽屉，点"☰ 选择年级"就能展开；
• 技巧按顺序解锁，前面的"融会贯通"了，后面的才开放，像打游戏升级。

七、第四步：薄弱点——连对两次才算真会

练习时做错的题，会自动记进「薄弱点」。但光"记下来"没用，得有机制逼孩子真正掌握。我定的规则是：

• 做错 → 记入薄弱点，连对计数清零；
• 做对 1 次 → 记 1 次通过，但暂时不消除（防止"假性掌握"）；
• 同类题再做对 1 次（连对 2 次）→ 才正式从薄弱点移除。

"薄弱点复习"页会专门把这些都列出来，一道道攻克；全部清零了，页面会告诉你"暂时没有薄弱点，继续保持"。

八、第五步：手机能用，单文件带走

有家长把整个文件夹拷进手机、直接点开 index.html，结果只看到白底文字——因为手机的文件预览会拦掉外部样式和脚本。我顺手做了个自包含单文件版 math-mastery-standalone.html：

• 把全部 CSS 和 JS 都内联进这一个文件，没有任何外部依赖；
• 下载这一个文件，拷进手机，点开即用，不用 NAS、不用服务器；
• 同时把顶部导航、目录抽屉都做了手机适配，窄屏不再挤成"坏页面"。

安卓 Chrome 里进度和薄弱点也能正常保存；iOS 系统限制较多，建议用 Safari 打开。

九、第六步：AI 知识漏洞诊断（纯本地，不联网）

薄弱点记多了，"先攻哪个"又成了问题。最新一版我加了个「AI诊断」页——注意，这是规则引擎，跑在浏览器本地，不联网、不上传数据，绝不是把孩子的信息发到某个大模型：

• 扫描所有未清零的薄弱点，按做错次数、距上次练习时长、是否已连对一次算一个综合严重度；
• 画出小学/初中/高中各学段的掌握度，以及薄弱点按年级分布；
• 给一句人话结论，比如"高中梯度是首要薄弱点，建议优先攻克"；
• 点「开始专属训练套餐」，按严重度权重自动混出一份个性化练习（重度 3 题、中度 2 题、轻度 1 题）。

相当于给孩子配了个"本地私教"，只在本机算，数据哪也不去。

十、怎么拿到手（三种方式）

方式一 · 家里有 NAS（推荐，体验最完整）：把项目 git 拉到 NAS，用一条 python3 -m http.server 8142 起个静态服务，局域网内手机/电脑访问 http://NAS的IP:8142 即可。进度持久、更新只需 git pull。
方式二 · 手机直接打开：下载 math-mastery-standalone.html 这一个文件，拷进手机点开就能用，零配置。
方式三 · 电脑浏览器：直接双击 index.html（或起个本地静态服务），桌面大屏看讲解和动图更清楚。
